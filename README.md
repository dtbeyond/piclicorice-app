# PicLicorice

PicLicorice is Aime's skincare coaching and shopping app.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The app is configured for static export and publishes the `out` directory on Netlify.

## Environment

Copy `.env.example` to `.env.local` and add the Supabase public URL and anon key.
